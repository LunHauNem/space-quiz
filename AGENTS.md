# Project rules

- Keep the quiz self-contained in `index.html`; do not add a server, build step, package, or remote dependency.
- Preserve the 10-question flow, scoring, progress, answer feedback, results, and light/dark themes.
- Keep the layout narrow, centered, responsive, and consistent with the space mission-control look.
- Use semantic, keyboard-focusable controls, visible focus, readable contrast, and reduced-motion support.
- Verify interaction and appearance in the integrated browser, including both themes.
